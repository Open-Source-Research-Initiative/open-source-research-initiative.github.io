# OSRI website publishing

The website is built from the public OSRI hub. Read that repository's instructions before changing its content or site builder.

- Keep research guides, catalogs, and records in `Open-Source-Research-Initiative/osri`.
- This repository owns the GitHub Pages publishing workflow. Do not copy editable research content here.
- Check the generated site before deployment. Preserve source references, translation status, and the recorded scope of activity counts.
- Keep credentials out of files. The workflow uses GitHub's built-in token and Pages identity permissions.
- Publish authorized changes through a pull request. Do not claim human review when only agent checks occurred.
